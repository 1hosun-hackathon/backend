# backend
1hosun_backend

## Git 컨벤션

### 라벨

| 라벨 | 설명 |
|------|------|
| Feat | 새로운 기능 추가 또는 기존 기능 개선 |
| Fix | 버그 수정 또는 오류 해결 |
| Refactor | 기존 기능에 영향을 주지 않는 설계·내부 구조 변경 |
| Design | UI/UX 또는 디자인 관련 변경사항 |
| Chore | 빌드 시스템, 라이브러리 업데이트, 코드 스타일 등 내부 관리 |
| Setting | 프로젝트 환경 설정 또는 구성 파일 변경 |
| Comment | 주석, 로그 출력 관련 변경 |
| Docs | 문서 수정 |
| Test | 테스트 코드 추가 및 수정 |

목록에 없는 라벨은 만들지 않는다.

### 이슈

제목: `[{라벨}] {목표 한 줄}` (예: `[Design] 디자인 토큰 및 Pretendard 적용`)

```markdown
## 목적
## 범위
### 포함:
- 
### 제외:
- 
## 작업 내용
- [ ] 
## 완료 조건
- [ ]
```

### 커밋

형식: `[{Label}/{Issue Number}] {Label}: {message}`

예: `[Feat/#12] Feat: 로그인 화면 JWT 인증 추가`

### PR

제목: `[{라벨}/{Issue 번호}] 작업 요약` (예: `[Chore/#2] Tailwind 종속성 추가`)

```markdown
## 연관 Issue
(예: Closes #12, Refs #34)
## 요약
## 작업 내용
- 
## 범위
### 포함:
- 
### 제외:
- 
## 스크린샷 / 미리 보기
```
